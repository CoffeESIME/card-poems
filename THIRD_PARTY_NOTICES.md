# Avisos de terceros

El proyecto utiliza paquetes de código abierto. Se conservan sus licencias originales en `node_modules` tras `npm install`.

| Recurso            | Licencia                  | Archivo de referencia                                          |
| ------------------ | ------------------------- | -------------------------------------------------------------- |
| Cormorant Garamond | SIL Open Font License 1.1 | `node_modules/@fontsource/cormorant-garamond/LICENSE`          |
| DM Sans            | SIL Open Font License 1.1 | `node_modules/@fontsource/dm-sans/LICENSE`                     |
| Noto Serif JP      | SIL Open Font License 1.1 | `node_modules/@fontsource/noto-serif-jp/LICENSE`               |
| Noto Naskh Arabic  | SIL Open Font License 1.1 | `node_modules/@fontsource/noto-naskh-arabic/LICENSE`           |
| Lucide React       | ISC                       | `node_modules/lucide-react/LICENSE`                            |
| React y React DOM  | MIT                       | `node_modules/react/LICENSE`, `node_modules/react-dom/LICENSE` |
| Vite               | MIT                       | `node_modules/vite/LICENSE.md`                                 |

Se incluyen copias de las licencias de fuentes e iconos en `public/licenses/`, que también se copian a la compilación distribuible.
